## Deviations and implementation notes
- Placeholders: plan limit `[5]`. Everything else is final copy; new copy listed below.
- Move earlier/later use up/down arrows because swatches are a vertical list (a horizontal list would need mirrored chevrons).
- «مسودة» is shown only on the list card and the kit header; the rule for when a kit stops being a draft is the backend's (design 3d assumes it follows the first save).
- Sidebar: «علاماتي التجارية» sits in the footer nav with الرصيد and الحساب, shown only when the agents API offers the designer (plan §3.1). The account-menu link is not drawn.
- Bidi: wrap hex values and `n / max` counters in `dir="ltr"` isolates; file names in `dir="ltr"`.
- Tokens: add none. Danger zone card uses `danger-border`.

## Approval (user, 2026-11-10)

Approved with these answers to the open questions:
1. Profile section title «الأسلوب والتعليمات».
2. «مسودة» comes only from the graphic designer agent: kits created on this page start `ready`, and a draft becomes ready only when the user confirms the summary in the chat. Saving on this page does not clear it, so frame 3d keeps the badge (built that way).
3. Only a draft's page shows a note «لم يكتمل إعداد هذه الهوية بعد» with a link to «مصمم جرافيك» in the chat, where the user picks the draft and finishes it step by step (F13, no AI). Ready kits get no shortcut.
4. The 40-file limit covers the whole kit: shown once at the top of the files section, by the «8 / 40» counter, with all four drop zones disabled.
5. The account-menu link matches the sidebar link; no separate frame.
